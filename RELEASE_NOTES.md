SideRelay 0.5.0

- Монохромный интерфейс с нативным Liquid Glass, мягкими переходами и поддержкой Reduce Motion.
- Setup из четырёх шагов: сеть, целевое устройство, IPA и учётная запись, подтверждение установки.
- Русский и английский для интерфейса, системного запроса доступа к сети и сообщений ядра. Язык следует настройкам iOS.
- «Модем» в Setup: подключение к раздаче первого устройства без роутера, с подписью через мобильные данные. Сопряжение через модем не проверено на двух физических устройствах.
- Ethernet в Setup: проверка проводного пути на первом устройстве и инструкция для двух адаптеров со статическими IPv4. Интернет для Apple Account остаётся обязательным. Установка через Ethernet не проверена на физических устройствах; USB-C напрямую не поддерживается.
- Обновление через SideStore поверх предыдущей версии.
